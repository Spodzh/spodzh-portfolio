# Spodzh — Портфолио

Персональный сайт-портфолио видеомонтажёра, контент-мейкера и художника Spodzh (Влад).

🌍 **Живой сайт:** https://ТВОЙ_НИК.github.io/spodzh-portfolio/

## О проекте
- Тёмная тема с неоновыми акцентами (синий / красный)
- Адаптивный дизайн (телефон + ПК)
- Анимации появления, плавный скролл
- Чистый HTML / CSS / JavaScript — без фреймворков

## Как обновить контент
- **Текст, проекты, услуги** → редактируй `index.html`
- **Цвета, шрифты, стили** → `style.css` (переменные в `:root`)
- **Фото** → клади в папку `assets/` и подставляй в `index.html`
